# 薇薇 · 三特写

## 1. 固定目标

默认生成同一人物、同一造型、同一情境的三张独立图片，不拼图：

| 槽位 | 默认范围 | 核心目标 |
|---|---|---|
| 头部 | 发顶附近至下巴，必要时少量领口 | 面部结构、表情与生命感 |
| 腰胸臀 | 锁骨下方至大腿上段，头脚出画 | 胸腰胯体量对照、腰线与服装贴合 |
| 脚腿 | 大腿至足部，头部与躯干出画 | 大腿主导、小腿次之、足部收束；结构、透视与材质 |

题材改变表现方式，不改变三个槽位。
每张只设一个视觉中心，光线、锐度、细节与道具为它服务。

执行适用的内容限制。身材强调采用明确成年主体；不得通过修改年龄标签成人化未成年角色。

## 2. 创作推演

将用户指令拆为：**主体 × 媒介 × 风格 × 事件 × 造型 × 情境。**

区分用户明确要求、角色固定特征与可自由设计项。
结合上下文执行，不重复询问是否启用薇薇。

按媒介转译核心目标：

- 写真 / cos：真实表情、承重、布料与摄影光线。
- 二次元插画：五官设计、轮廓节奏、色块与线条。
- 电影帧：情绪潜台词、动作瞬间与叙事光线。
- 游戏CG：角色辨识度、目标渲染风格与材质。
- Live2D宣传视觉：二维立绘质感的静态图；不等于动画模型。

给三张安排同一事件或连续瞬间。
事件通过视线、手势和腿姿表达，道具不得遮住核心部位。

生成前简短说明：**本次理解、锁定特征、三张打法、必要取舍。**
信息足够直接执行；仅在关键歧义会改变作品时提问。

## 3. 参考与一致性

不建批量候选池，不默认等待选图。

- 指定角色：优先官方立绘、角色页或游戏截图。
- 指定人物：采用用户提供的参考。
- 指定作品风格：必要时补代表画面。
- 原创主题：信息足够直接设计。

默认用1—3张有效参考；用途明确、信息足够即停止。
读取实际图片，核对角色、服装版本与来源，防止同名误配。
允许多图分别负责人物、服装、风格和构图。

遮挡或不可见部分先补查；仍未知时标为自创或不确定，不得声称官方还原。关键特征缺失时不能凭空补完。

建立共用设定：**面容、妆发、服装、配饰、鞋袜、事件、场景、主光与画风。**

三张仅变化机位、裁切、局部动作和合理补光。
人物特征、服装结构与光源逻辑保持一致。
不擅自添加丝袜、缩裙、脱衣或更换角色服饰。

## 4. 提示词

每张按顺序写：**核心目标 → 共用设定 → 构图结构 → 动作 → 明暗层级 → 媒介材质 → 必要限制。**

只描述实际入画内容。首轮选少量关键特征，不用伪精确数字、重复形容词或解剖术语堆砌。
优先正面空间描述，出现具体错误后再加修复约束。

### 头部

脸占绝大部分画面，手默认出画。
先确定事件、视线对象和表情，再写2—3处联动变化。
表情服从题材，不默认甜笑；双眼方向与眼睑状态协调。
真人保留皮肤质感，插画不强加毛孔，CG保留角色面容。
光线塑造面部起伏，不让头饰或背景抢戏。

### 腰胸臀

腰线为中心，胸与胯形成体量对照，不均分画面。
先确定胸廓、腰、骨盆与承重，再表现衣料张力和褶皱。
宽袍或护甲通过轮廓、接缝和明暗表现体量，不擅自换装。
手仅在动作需要时出现；检查可见指节、腕臂连接与遮挡，不强求五指全部展开，不靠模糊隐藏错误。
道具、手和头发保持次要权重。

### 脚腿

明确可见腿、踝、脚的数量、连接、朝向、前后与遮挡。
比例服从可信透视，不同时要求相互冲突的远近关系。
大腿主导，小腿过渡，足部收束；材质服从角色造型。
高光沿曲面变化，交叠处用阴影分隔体积。
手默认出画；足趾可裁出画，完整足部也不自动算错。
环境仅提供必要空间线索。

## 5. 冲突与生成

遵守用户要求。内部冲突依次保住：**结构自洽 → 固定槽位与核心目标 → 角色和媒介辨识度 → 整组一致性 → 装饰细节。**

先调整机位、裁切、遮挡和动作幅度；仍无法兼容时说明，不默默改变关键要求。
风格化允许合理夸张与省略，不允许错接、多肢或透视崩坏。

使用实际可用的生成工具，每张独立调用：

- 一致性要求高：先确立一张，再结合原始参考扩展其余两张。
- 参考充分且造型简单：可共用设定并发生成。

后续不能只参考首张，避免传播首张错误。
分别记录各张结果，一张失败不重跑其他成功图。

## 6. 默认检查与修复

每张完成后检查，整组完成后核对一致性：

1. 结构：人体连接、关节、手指、遮挡、透视。
2. 槽位：裁切正确，核心目标清楚。
3. 还原：人物、造型、媒介未明显偏离。
4. 一致性：三张身份、服饰、道具与光线相容。

结论：**通过 / 失败 / 无法判断。**
不清楚时查看一次局部；仍不清楚就保留不确定。
画外与合理遮挡部分不要求凭空验证。

默认每个失败槽位最多定向修复一次，再检查后交付。
不把生成成功当作质量通过，不无限追加次数。

技术失败按工具规则有限重试。
内容拒绝不通过反复改写绕过；替代方案若改变角色服装、固定槽位或核心动作，保留成功图，说明缺项与替代，待用户接受后执行。

## 7. 迭代

用户要求时启用：
“迭代N轮”指首轮之外最多N轮；“总共N轮”包含首轮。简短说明计数即可。

只重做待改槽位，每张保留当前最佳版。
裁判每张给出：

- 结构、槽位、还原结论；
- 核心目标：达到 / 接近 / 未达到；
- 具体证据；
- 下一轮最重要的一项改动；
- 必须保留的成功部分；
- 是否替换最佳版。

先修硬伤，每轮修改一个主要变量。
已达标槽位冻结；所有质量修复计入迭代轮数，不另加默认修复次数。

达标、预算耗尽或路线受限时停止。
从各轮选最佳三张，再核对整组一致性；最后一轮不自动等于最佳版。

## 8. 交付

展示独立成片，简述重点、最终版本与实际未解决问题。
缺图如实报告，不以改变题材凑足数量。

区分新生成图与官方原图、静态图与Live2D模型、近似游戏风格与官方游戏资产。

默认不附长篇提示词和审片日志。
未经用户要求，不自动修改本skill。
